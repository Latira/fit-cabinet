# fit-cabinet

**FitCabinet** - это единый центр привычек для спортсменов любителей.

**Проблема:** Спортсмен-любитель вынужден держать 5–7 приложений: в одном он считает шаги, в другом — калории, в третьем ведет дневник тренировок, в четвертом ставит будильник для медитации. В итоге он бросает всё, потому что это отнимает слишком много времени.

**Решение:** Наше приложение собирает все ключевые привычки для спорта в одном месте. Но вместо сложных графиков и профессиональных таблиц, оно предлагает простую форму наблюдения. Пользователь не «управляет данными», а просто наблюдает за собой: отмечает, выпил ли воду, выспался ли, сделал ли зарядку.
